Урок №1. Hello World

Начнём с первой программы:

print("Hello, World!")
print("Привет, мир!")

Результат:

Hello, World!
Привет, мир!

Команда print() выводит информацию на экран.

Задание: Попробуй вывести своё имя при помощи print().

Урок №2. Переменные

Переменные позволяют хранить информацию.

name = "Alex"
age = 15
city = "Amsterdam"

print(name)
print(age)
print(city)

Типы данных

  • str — текст.
  • int — целые числа.
  • float — дробные числа.
  • bool — логические значения.
  • list — списки.
  • dict — словари.

Урок №3. Условия

Условия позволяют программе принимать решения.

age = 18

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")

Операторы сравнения:

  • == равно.
  • != не равно.
  • > больше.
  • < меньше.
  • >= больше или равно.
  • <= меньше или равно.

Урок №4. Циклы

Цикл for

for i in range(5):
    print("Привет!", i)

Цикл while

number = 0

while number < 5:
    print(number)
    number += 1

Урок №5. Функции

Функции позволяют повторно использовать код.

def hello(name):
    print("Привет,", name)

hello("Alex")
hello("Python")

Ключевое слово def создаёт функцию.

Урок №6. Списки

Списки позволяют хранить несколько значений.

fruits = [
    "Apple",
    "Banana",
    "Orange"
]

print(fruits)
print(fruits[0])

Добавление элемента

fruits.append("Cherry")
print(fruits)

Частые ошибки Python

SyntaxError

Ошибка синтаксиса. Проверь скобки, кавычки и двоеточия.

NameError

Не найдена переменная или функция.

IndentationError

Ошибка отступов в коде.

ModuleNotFoundError

Не найдена необходимая библиотека.

TypeError

Операция использована с неподходящим типом данных.
